# 🌱 Wyoming N-P-K Fertility Calculator

A C++ soil fertility decision-support tool that translates soil test results and field information into **N, P₂O₅, and K₂O fertilizer recommendations** using the University of Wyoming Guide to Fertilizer Recommendations.

## Features

* Soil-test N, P, K, and organic matter inputs
* Multiple crop recommendation modules
* Soil texture and water-supply inputs
* Yield-goal adjustments
* Cropping-history and manure N adjustments
* Urea, DAP, and KCl application calculations
* Final N-P₂O₅-K₂O recommendations in lb/acre

## Purpose

This project combines **agronomy, soil science, and C++ programming** to demonstrate how agricultural nutrient-management guidelines can be translated into a practical computational tool.

**Source:** University of Wyoming Guide to Fertilizer Recommendations / USDA-NRCS Agronomy Technical Note No. 10.

> This is an educational decision-support project and is not an official NRCS software product.
